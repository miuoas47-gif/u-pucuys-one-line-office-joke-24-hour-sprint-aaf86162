One original, funny one-line office joke for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty: a manager tells an employee to treat the job like their own business, and the employee takes the advice a little too literally.

> My manager told me to treat this job like it's my own business, so I immediately started looking for someone else to do the work.

## Run it

```sh
python3 main.py
```

Running `main.py` with no arguments prints the joke to stdout and writes it as a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).
